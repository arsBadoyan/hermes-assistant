Privacy Policy

Hermes Personal Assistant · last updated 12 November 2026

Hermes Personal Assistant is a private application used only by its owner, Arsen Badoian. It has no other users.

Data accessed

With the owner's consent, the application accesses data in the owner's own Google account: Gmail messages and settings, Google Calendar events, and Google Drive, Docs and Sheets files, within the scopes he approves.

How data is used

The data is used solely to perform tasks the owner asks for, such as finding, summarising, organising and drafting emails, events and documents. It is not sold, not used for advertising, and not shared with third parties, except for processing by the AI model provider the owner uses to run the assistant.

Storage and security

OAuth tokens and working files are stored on a private server controlled by the owner, with access restricted to the owner. Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
